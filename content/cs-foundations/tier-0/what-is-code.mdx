Before touching syntax, get the mental model right: a computer is a machine that follows
instructions with zero judgment and zero patience for ambiguity. "Code" is just instructions
written precisely enough that a machine can follow them.

## What you'll leave this lesson knowing

- The difference between source code, a compiler/interpreter, and a running program
- What a terminal/shell is, and how to open one on your OS
- How to create, save, and run the smallest possible program in one language of your choice
- Why "it works on my machine" is a real phenomenon (environments, not magic)

## Do this

1. Open a terminal. Run `pwd` (or `cd` on Windows) and read what it prints — that's "where you are."
2. Create a file called `hello.txt` from the terminal (not a GUI). Look up the command if you don't know it — this is the first of many times you'll search for a command and that is completely normal, not a sign you're behind.
3. Install one language runtime (Python is the easiest first choice) and run a one-line program that prints `Hello, Manual`.

## Check on learning

- Explain, out loud or in writing, what happened between you saving `hello.py` and text
  appearing in your terminal. If you can't yet, that's the honest starting point — not a problem.
